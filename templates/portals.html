Device lock:
Leave this off unless the portal refuses a MAC that works on your box or in STB Emulator.
These MACs have different device details. To change them, edit devices.json next to config.json.

Copy these from the box the MAC belongs to. In STB Emulator they're under Settings → Profiles → your profile → STB configuration. On a MAG box the serial number is in Settings → System information.
Start with just the model and serial number: many portals only check those. If the portal still refuses the MAC, add the device IDs and signature. Try one change at a time: some portals briefly refuse logins after several in a row.

Advanced Anything else the portal checks, as JSON with any of cookies, headers, handshake and profile. They're sent with the box's requests as they are. Some portals need values captured from the box's own login (for example signatures that change per request).
